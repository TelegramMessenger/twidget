# LiteHTMLKit

A fast, sandboxed HTML/CSS renderer for native apps, built on a heavily optimized fork of [litehtml](https://github.com/litehtml/litehtml). It powers the interactive HTML messages in Telegram for macOS.

Work in progress: this first commit is a snapshot of the code as it ships in the app. The portable C++ core, the painter, text, image and script interfaces, and the documentation follow.
